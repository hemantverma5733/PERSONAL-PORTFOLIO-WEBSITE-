Library Management System

Java SQL Swing

Developed using Java and DBMS to manage library inventories, user records, and borrowing systems efficiently with an intuitive UI.

Live Demo 🚀 
public class LibrarySystem {
    public void borrowBook(String userId, String bookId) {
        if (checkAvailability(bookId)) {
            updateInventory(bookId, -1);
            recordTransaction(userId, bookId, "BORROW");
            System.out.println("Book borrowed successfully!");
        } else {
            System.out.println("Book is currently unavailable.");
        }
    }
}

Smart BMI Calculator

C++ CLI

A fast C++ utility application for calculating Body Mass Index based on health metrics, providing instant health insights.

Live Demo 🚀 
#include 
using namespace std;

double calculateBMI(double weight, double height) {
    return weight / (height * height);
}

int main() {
    double bmi = calculateBMI(70.5, 1.75);
    cout << "Your BMI is: " << bmi << endl;
    return 0;
}
